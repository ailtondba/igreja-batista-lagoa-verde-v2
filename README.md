## Instalação e Uso

### Pré-requisitos
- Navegador web moderno
- Servidor web (para desenvolvimento local)

### Instalação Local
1. Clone o repositório:
   ```bash
   git clone https://github.com/ailtondba/igreja-batista-lagoa-verde-v2.git
   ```

2. Navegue até o diretório:
   ```bash
   cd igreja-batista-lagoa-verde-v2
   ```

3. Abra o arquivo `index.html` em um navegador ou use um servidor local:
   ```bash
   # Usando Python
   python -m http.server 8000
   
   # Usando Node.js
   npx http-server
   ```

### Deploy
O projeto está configurado para deploy no Firebase Hosting:

1. Instale o Firebase CLI:
   ```bash
   npm install -g firebase-tools
   ```

2. Faça login no Firebase:
   ```bash
   firebase login
   ```

3. Inicialize o projeto:
   ```bash
   firebase init hosting
   ```

4. Faça o deploy:
   ```bash
   firebase deploy
   ```
